# 🌐 LanguageAI

LanguageAI is an AI-powered multilingual language translation web application built using Python and Streamlit.

## 🚀 Features

- Multi-language translation
- AI-powered translation
- Speech output support
- Modern responsive UI
- Copy-friendly translated text
- Beautiful maroon-black theme

## 🛠 Technologies Used

- Python
- Streamlit
- deep-translator
- gTTS

## ▶ How to Run

```bash
streamlit run app.py
